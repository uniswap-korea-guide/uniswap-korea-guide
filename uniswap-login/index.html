비밀번호 로그인을 찾고 있다면

“유니스왑 로그인”을 검색해도 별도의 계정 비밀번호 입력 페이지를 찾는 방식은 적절하지 않습니다. 공식 웹 앱에서 Connect 기능으로 지갑을 연결하는 흐름을 사용하세요.

보안 체크복구 문구, 시드 문구, 개인키를 웹사이트나 “지원팀”에게 전달하지 마세요. 이 사이트에서도 어떤 지갑 정보도 입력받지 않습니다.

복구 문구는 로그인 정보가 아님

시드 문구나 복구 문구를 웹사이트 로그인 칸에 입력하면 안 됩니다. 지갑 복구는 해당 지갑의 공식 복구 흐름에서만 진행해야 합니다.

연결 후 확인

지갑 주소가 웹 앱에 표시되는지 확인하고, 거래를 진행할 때는 각 서명 요청의 내용을 지갑 화면에서 검토하세요.

공식 경로 바로가기

거래나 지갑 연결은 아래 공식 서비스에서 직접 진행하세요. 이 사이트는 거래 기능을 제공하지 않습니다.

공식 웹 앱 ↗공식 Wallet ↗공식 지원 센터 ↗공식 개발 문서 ↗

마지막 체크

거래를 실행하기 전에는 현재 접속한 도메인, 연결한 지갑 주소, 네트워크, 토큰, 예상 수령량과 지갑의 최종 서명 내용을 다시 확인하세요. 이 가이드는 일반 정보이며 투자·법률·세무 조언이 아닙니다.
