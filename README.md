# uniswap-korea-guide

정적 HTML SEO 프로젝트. Vercel에 GitHub 저장소를 연결해 바로 배포할 수 있습니다.

## 기본 URL
https://uniswap-korea-guide.vercel.app

## SEO 핵심
- 메인 키워드: `유니스왑`
- 각 인덱스 페이지에 canonical 설정
- `sitemap.xml`, `sitemap.txt`, `robots.txt`, `404.html` 포함
- Google Search Console HTML 검증 파일을 저장소 루트에 넣도록 구성
- 한국어 `lang=ko`, Open Graph, Article/WebSite 구조화 데이터 포함

## Search Console
`google-site-verification-PLACEHOLDER.html` 파일은 실제 검증 파일이 아닙니다. Search Console에서 받은 원본 `.html` 파일을 저장소 루트에 그대로 업로드하세요.

## 브랜드/상표
이 프로젝트의 표시 브랜드는 **온체인 가이드**입니다. Uniswap 명칭은 설명 대상 서비스를 지칭하기 위한 문맥에서 사용하며, 사이트에는 독립성 및 상표 고지를 포함했습니다.

## 공식 링크
거래, 지갑 연결, 지원은 각 페이지에서 공식 Uniswap 웹 앱 / Wallet / Support / Docs로 직접 연결합니다.
